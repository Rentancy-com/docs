---
title: "Email History and Send — Lofty Communication API"
description: "List email history for a lead and send outbound emails using the Lofty API. Covers GET /v1.0/communication/email and POST /v1.0/message/email/send."
---

The Lofty API lets you both retrieve a lead's email history and send new outbound emails on behalf of an agent.

## List email history

```
GET https://api.lofty.com/v1.0/communication/email
```

<ParamField query="leadId" type="integer" required>
  ID of the lead whose email history to return. Must belong to the caller's team.
</ParamField>

<ParamField query="offset" type="integer">
  Zero-based index of the first entry to return.
</ParamField>

<ParamField query="limit" type="integer">
  Number of entries per page.
</ParamField>

<ParamField query="currentId" type="integer">
  Cursor for pagination. Pass the last seen entry ID to get the next page.
</ParamField>

```bash
curl "https://api.lofty.com/v1.0/communication/email?leadId=563172647619608&limit=20" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

## Send an email

```
POST https://api.lofty.com/v1.0/message/email/send
```

<ParamField body="leadId" type="integer" required>
  ID of the lead to send the email to.
</ParamField>

<ParamField body="subject" type="string" required>
  Email subject line.
</ParamField>

<ParamField body="content" type="string" required>
  Email body content.
</ParamField>

<ParamField body="toEmail" type="string">
  Specific email address on the lead to send to. If omitted, the lead's primary email is used.
</ParamField>

```bash
curl -X POST "https://api.lofty.com/v1.0/message/email/send" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "leadId": 563172647619608,
    "subject": "Following up on your property search",
    "content": "Hi Jane, I wanted to follow up on the listings we discussed last week..."
  }'
```

## Example response

```json
{
  "success": true,
  "messageId": "email_789012345678"
}
```

<Note>
  The caller must have manage permission on the lead and must have an outgoing email configuration set up in Lofty.
</Note>
