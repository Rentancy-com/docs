---
title: "SMS History and Send — Lofty Communication API"
description: "List text message history for a lead and send outbound SMS using the Lofty API. Covers GET /v1.0/communication/text and POST /v1.0/message/sms/send."
---

Use these endpoints to retrieve a lead's SMS history and send text messages from an agent's virtual number in Lofty.

## List SMS history

```
GET https://api.lofty.com/v1.0/communication/text
```

<ParamField query="leadId" type="integer" required>
  ID of the lead whose text message history to return. Must belong to the caller's team.
</ParamField>

<ParamField query="offset" type="integer">
  Zero-based index of the first entry to return.
</ParamField>

<ParamField query="limit" type="integer">
  Number of entries per page.
</ParamField>

<ParamField query="currentId" type="integer">
  Cursor for pagination. Pass the last seen entry ID to get the next page.
</ParamField>

```bash
curl "https://api.lofty.com/v1.0/communication/text?leadId=563172647619608&limit=20" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

## Send an SMS

```
POST https://api.lofty.com/v1.0/message/sms/send
```

<ParamField body="leadId" type="integer" required>
  ID of the lead to send the SMS to.
</ParamField>

<ParamField body="content" type="string" required>
  Text message content.
</ParamField>

<ParamField body="phoneNumber" type="string">
  Specific phone number on the lead to text. If omitted, the lead's primary phone is used.
</ParamField>

<ParamField body="phoneCode" type="string">
  Country code for the phone number (e.g., `1` for US). Required when `phoneNumber` is specified.
</ParamField>

```bash
curl -X POST "https://api.lofty.com/v1.0/message/sms/send" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "leadId": 563172647619608,
    "content": "Hi Jane! Just checking in — are you still interested in properties in the Austin area?"
  }'
```

## Example response

```json
{
  "success": true,
  "messageId": "sms_456789012345"
}
```

<Note>
  The caller must have manage permission on the lead and must have an active virtual number configured in Lofty to send SMS messages.
</Note>
