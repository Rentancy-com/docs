---
title: "Lead Activity Timeline — Lofty API"
description: "Retrieve a unified timeline of call, text, and email activities for a Lofty lead, including both auto-captured and agent-logged entries."
---

The activity endpoints give you a complete communication history for any lead. Two separate endpoints cover different types of activity:

- **`GET /v2.0/leads/{leadId}/activities`** — Unified timeline of calls, texts, and emails (recommended).
- **`GET /v1.0/leads/{leadId}/activities`** — Site-tracked activities: property browsing, searches, favorites, and showing requests.
- **`POST /v1.0/leads/{leadId}/activity`** — Log an external communication or site interaction manually.

---

## GET /v2.0/leads/{leadId}/activities

Returns a unified list of call, text, and email activities for the given lead, including both auto-captured entries and those logged manually by agents. Results are sorted by `activityTime` ascending.

The caller must have access to the lead. If the lead does not exist or is inaccessible, the API returns `404 LEAD_NOT_EXIST`.

### Path parameters

<ParamField path="leadId" type="integer" required>
  The ID of the lead (64-bit integer).
</ParamField>

### Query parameters

<ParamField query="limit" type="integer">
  Number of activities to return. Accepted range: 1–1000. Defaults to 10.
</ParamField>

<ParamField query="offset" type="integer">
  Offset for offset-based pagination. Ignored when `currentId` is greater than 0. Defaults to 0.
</ParamField>

<ParamField query="currentId" type="integer">
  Cursor for cursor-based pagination. Pass the `id` of the last returned item to fetch the next page. Defaults to 0 (first page).
</ParamField>

<ParamField query="timeZoneCode" type="string">
  IANA timezone string (e.g., `America/Los_Angeles`). Affects how `activityTime` is formatted in the response. Defaults to UTC.
</ParamField>

### Example request

```bash
curl "https://api.lofty.com/v2.0/leads/563172647619608/activities?limit=50&offset=0" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

### Response fields

Each item in the `activities` array includes:

<ResponseField name="id" type="integer">
  Timeline ID (64-bit integer). Use this as `currentId` to fetch the next page.
</ResponseField>

<ResponseField name="leadId" type="integer">
  The ID of the lead this activity belongs to.
</ResponseField>

<ResponseField name="agentId" type="integer">
  The ID of the agent who initiated or logged the activity.
</ResponseField>

<ResponseField name="activityTime" type="string">
  The time of the activity in ISO 8601 format (e.g., `2026-03-19T10:30:00-07:00`).
</ResponseField>

<ResponseField name="channel" type="string">
  Communication channel: `Call`, `Text`, or `Email`.
</ResponseField>

<ResponseField name="communicationType" type="string">
  How the activity was captured: `Auto` (system-captured), `Manual` (agent-logged in UI), or `Logged` (logged via API).
</ResponseField>

<ResponseField name="direction" type="string">
  Direction of the communication: `Inbound` or `Outbound`.
</ResponseField>

<ResponseField name="callingOutcome" type="string">
  Call outcome. Populated for `Call` activities only. Example values: `Talked`, `No Answer`.
</ResponseField>

<ResponseField name="leadPhoneNumber" type="string">
  The lead's phone number involved in the call. Populated for `Call` activities only.
</ResponseField>

<ResponseField name="emailEventType" type="string">
  Email event. Populated for `Email` activities only. Example values: `Sent`, `Opened`, `Bounced`.
</ResponseField>

<ResponseField name="emailSubject" type="string">
  Email subject line. Populated for `Email` activities only.
</ResponseField>

<ResponseField name="note" type="string">
  Agent's note content. Populated for manually `Logged` activities only.
</ResponseField>

## GET /v1.0/leads/{leadId}/activities

Returns site-tracked activities for the lead — property browsing, searches, favorites, CMA views, and showing requests. Results are sorted by creation time descending.

Page size is fixed at 100 entries. Use `curPage` to step through pages.

### Path parameters

<ParamField path="leadId" type="integer" required>
  The ID of the lead (64-bit integer).
</ParamField>

### Query parameters

<ParamField query="curPage" type="integer">
  Zero-based page index. Page size is fixed at 100. Defaults to 0.
</ParamField>

### Example request

```bash
curl "https://api.lofty.com/v1.0/leads/563172647619608/activities?curPage=0" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

## POST /v1.0/leads/{leadId}/activity

Logs an external communication or site interaction for a lead. Use this when an interaction happened outside Lofty's tracking system — for example, a call made from a third-party dialer.

### Path parameters

<ParamField path="leadId" type="integer" required>
  The ID of the lead (64-bit integer).
</ParamField>

### Request body

<ParamField body="type" type="string" required>
  Activity type. Accepted values: `Search`, `Browse`, `Favorite`, `Request`, `Submission`.
</ParamField>

<ParamField body="text" type="string" required>
  Description of the activity. For search activities, use the search query text.
</ParamField>

<ParamField body="link" type="string" required>
  URL of the page associated with the activity.
</ParamField>

<ParamField body="picture" type="string" required>
  Preview image URL for the activity.
</ParamField>

<ParamField body="created" type="integer" required>
  Timestamp of the activity in milliseconds since Unix epoch (UTC).
</ParamField>

<ParamField body="listing" type="object">
  Property details associated with the activity (used for `Browse`, `Favorite`, and `Request` types).
</ParamField>

<ParamField body="scheduledDate" type="string">
  Scheduled date for a showing request. Used when `type` is `Request`.
</ParamField>

<ParamField body="pageName" type="string">
  Name of the page where the activity occurred. Example: `Blog Registration`.
</ParamField>

### Example request

```bash
curl -X POST https://api.lofty.com/v1.0/leads/563172647619608/activity \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "Browse",
    "text": "123 Main St, Austin, TX",
    "link": "https://example.com/listing/123-main-st",
    "picture": "https://example.com/images/123-main-st.jpg",
    "created": 1747272300000
  }'
```
