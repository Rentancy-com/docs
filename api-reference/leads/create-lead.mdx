---
title: "POST /v1.0/leads — Create a Lead"
description: "Create a new lead in Lofty with contact details, lead type, source, tags, inquiry preferences, and optional direct agent assignment."
---

Creates a new lead record. If `assignedUserId` is provided, the lead is directly assigned to that agent and routing rules are skipped. If `assignedUserId` is omitted, the lead is routed automatically according to your team's configured routing rules.

## Request body

### Contact information

<ParamField body="firstName" type="string" required>
  The lead's first name. Maximum 30 characters.
</ParamField>

<ParamField body="lastName" type="string">
  The lead's last name. Maximum 30 characters.
</ParamField>

<ParamField body="emails" type="array">
  List of email addresses associated with the lead.
</ParamField>

<ParamField body="phones" type="array">
  List of phone numbers. Each entry must not exceed 20 characters.
</ParamField>

<ParamField body="birthday" type="string">
  Lead's date of birth. Format: `MMM d, yyyy` (e.g., `Jan 5, 1985`).
</ParamField>

<ParamField body="language" type="string">
  The lead's preferred language. Accepted values: `en`, `fr`, `de`, `es`, `zh-CN`, `zh-TW`, `ja`.
</ParamField>

<ParamField body="referredBy" type="string">
  Name of the person who referred this lead.
</ParamField>

### Classification

<ParamField body="leadTypes" type="array">
  Lead type IDs. Accepted values: `Other` (-1), `Seller` (1), `Buyer` (2), `Renter` (5), `Investor` (6).
</ParamField>

<ParamField body="source" type="string">
  Lead source name. Example: `Zillow`, `Website`, `Referral`.
</ParamField>

<ParamField body="stage" type="string">
  Pipeline stage name. Maximum 20 characters.
</ParamField>

<ParamField body="tags" type="array">
  Tag names to associate with the lead. **Replaces all existing tags.**
</ParamField>

<ParamField body="tagsAdd" type="array">
  Tag names to add. Existing tags are retained; only new tags are appended.
</ParamField>

<ParamField body="segments" type="array">
  Segment names to place the lead in. Each name must not exceed 30 characters.
</ParamField>

### Assignment

<ParamField body="assignedUserId" type="integer">
  User ID of the agent to directly assign this lead to (64-bit integer). When provided, automatic routing is skipped.
</ParamField>

<ParamField body="assignGroupId" type="integer">
  Routing rule scope when automatic routing is triggered. Pass `-1` to apply company-level routing.
</ParamField>

<ParamField body="ownershipScope" type="string">
  Visibility scope of the lead. Accepted values: `TEAM` (company-wide), `OFFICE`, `PERSONAL`.
</ParamField>

<ParamField body="ownershipId" type="integer">
  Required when `ownershipScope` is `OFFICE` or `PERSONAL`. Pass the office ID or agent ID.
</ParamField>

### Qualification

<ParamField body="buyingTimeFrame" type="string">
  Buyer's time frame. Accepted values: `1-3`, `3-6`, `6-12`, `12+`, `Just Looking`, `Refinancing`.
</ParamField>

<ParamField body="sellingTimeFrame" type="string">
  Seller's time frame. Accepted values: `1-3`, `3-6`, `6-12`, `12+`, `Just Looking`, `Refinancing`.
</ParamField>

<ParamField body="preQual" type="string">
  Pre-qualification status. Accepted values: `Yes`, `No`.
</ParamField>

<ParamField body="houseToSell" type="string">
  Whether the lead has a house to sell. Accepted values: `Yes`, `No`.
</ParamField>

<ParamField body="fthb" type="string">
  First-time home buyer. Accepted values: `Yes`, `No`.
</ParamField>

<ParamField body="mortgage" type="string">
  Needs mortgage. Accepted values: `Yes`, `No`.
</ParamField>

<ParamField body="buyHouse" type="string">
  Planning to buy a house. Accepted values: `Yes`, `No`.
</ParamField>

<ParamField body="withBuyerAgent" type="string">
  Already working with a buyer's agent. Accepted values: `Yes`, `No`.
</ParamField>

<ParamField body="withListingAgent" type="string">
  Already working with a listing agent. Accepted values: `Yes`, `No`.
</ParamField>

### Inquiry preferences

<ParamField body="inquiry" type="object">
  The lead's property search preferences.

  <Expandable title="inquiry fields">
    <ParamField body="priceMin" type="integer">Minimum price.</ParamField>
    <ParamField body="priceMax" type="integer">Maximum price.</ParamField>
    <ParamField body="bedroomsMin" type="integer">Minimum bedrooms.</ParamField>
    <ParamField body="bathroomsMin" type="string">Minimum bathrooms.</ParamField>
    <ParamField body="propertyType" type="array">
      Property types. Accepted values: `Single Family Home`, `Multi-Family`, `Condo`, `Townhouse`, `Mobile Home`, `Manufactured`, `Land`, `Commercial`.
    </ParamField>
    <ParamField body="locations" type="array">
      Areas the lead is interested in. Each entry may include `city`, `stateCode`, `zipCode`, `county`, `streetAddress`, and `description`.
    </ParamField>
  </Expandable>
</ParamField>

### Property

<ParamField body="property" type="object">
  Property or mailing address details. For Seller leads, values here affect routing.

  <Expandable title="property fields">
    <ParamField body="streetAddress" type="string">Street address.</ParamField>
    <ParamField body="city" type="string">City.</ParamField>
    <ParamField body="state" type="string">State.</ParamField>
    <ParamField body="zipCode" type="string">ZIP code.</ParamField>
    <ParamField body="price" type="integer">Listing price.</ParamField>
    <ParamField body="propertyType" type="string">Property type.</ParamField>
    <ParamField body="bedrooms" type="integer">Number of bedrooms.</ParamField>
    <ParamField body="bathrooms" type="number">Number of bathrooms.</ParamField>
    <ParamField body="squareFeet" type="integer">Square footage.</ParamField>
    <ParamField body="mailAddress" type="boolean">Set to `true` if this is a mailing address rather than the property address.</ParamField>
  </Expandable>
</ParamField>

### Custom fields

<ParamField body="customAttributeList" type="array">
  Custom field values for this lead.

  <Expandable title="customAttributeList item fields">
    <ParamField body="attributeName" type="string" required>Name of the custom field.</ParamField>
    <ParamField body="attributeType" type="string" required>Type of the custom field.</ParamField>
    <ParamField body="value" type="string" required>Value of the custom field. For multi-select, format as a JSON array string: `["item1","item2"]`.</ParamField>
  </Expandable>
</ParamField>

### Communication preferences

<ParamField body="cannotText" type="boolean">
  Set to `true` to opt the lead out of text messages.
</ParamField>

<ParamField body="cannotCall" type="boolean">
  Set to `true` to opt the lead out of calls.
</ParamField>

<ParamField body="cannotEmail" type="boolean">
  Set to `true` to opt the lead out of emails.
</ParamField>

<ParamField body="unsubscription" type="boolean">
  Set to `true` to unsubscribe the lead from marketing emails.
</ParamField>

<ParamField body="welcomeEmail" type="boolean">
  Send a welcome email to the lead on creation. Not applicable to updates.
</ParamField>

<ParamField body="leadAlert" type="boolean">
  Send a new lead alert email to the assigned agent. Not applicable to updates.
</ParamField>

## Example request

```bash
curl -X POST https://api.lofty.com/v1.0/leads \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "firstName": "Jane",
    "lastName": "Smith",
    "emails": ["jane.smith@example.com"],
    "phones": ["3105550142"],
    "source": "Zillow",
    "stage": "New Lead",
    "leadTypes": [2],
    "assignedUserId": 100234,
    "tags": ["Hot Lead", "Buyer"],
    "buyingTimeFrame": "3-6",
    "preQual": "Yes",
    "inquiry": {
      "priceMin": 400000,
      "priceMax": 750000,
      "bedroomsMin": 3,
      "propertyType": ["Single Family Home", "Condo"],
      "locations": [
        { "city": "Austin", "stateCode": "TX" }
      ]
    }
  }'
```

## Response

On success, the API returns the string ID of the newly created lead.

```json
"563172647619608"
```

<Note>
  The returned value is the `leadId` as a string. Store it as a string or 64-bit integer to avoid precision loss.
</Note>
