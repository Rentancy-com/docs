---
title: "GET /v1.0/leads/{leadId} — Get Lead Details"
description: "Retrieve a single Lofty lead by ID using GET /v1.0/leads/{leadId}. Returns contact info, stage, agent assignment, tags, lead score, and property details."
---

Returns a single lead record by ID. By default, trashed leads are not returned. Pass `withTrash=true` to include them.

The caller must have access to the lead. If the lead does not exist or is inaccessible, the API returns `404 LEAD_NOT_EXIST`.

## Path parameters

<ParamField path="leadId" type="integer" required>
  The ID of the lead to retrieve (64-bit integer).
</ParamField>

## Query parameters

<ParamField query="withTrash" type="boolean">
  When `true`, include trashed leads in the lookup. Defaults to `false`.
</ParamField>

## Example request

```bash
curl https://api.lofty.com/v1.0/leads/563172647619608 \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

## Response fields

<ResponseField name="leadId" type="integer">
  The unique ID of the lead (64-bit integer).
</ResponseField>

<ResponseField name="leadUserId" type="integer">
  The internal user ID associated with this lead record.
</ResponseField>

<ResponseField name="firstName" type="string">
  The lead's first name.
</ResponseField>

<ResponseField name="lastName" type="string">
  The lead's last name.
</ResponseField>

<ResponseField name="emails" type="array">
  List of email addresses associated with the lead.
</ResponseField>

<ResponseField name="phones" type="array">
  List of phone numbers associated with the lead.
</ResponseField>

<ResponseField name="birthday" type="string">
  The lead's date of birth.
</ResponseField>

<ResponseField name="source" type="string">
  The lead source name (e.g., `Zillow`, `Website`).
</ResponseField>

<ResponseField name="stage" type="string">
  The lead's current pipeline stage name.
</ResponseField>

<ResponseField name="stageId" type="integer">
  The ID of the lead's current pipeline stage.
</ResponseField>

<ResponseField name="assignedUserId" type="integer">
  The user ID of the assigned agent.
</ResponseField>

<ResponseField name="assignedUser" type="string">
  The account (email) of the assigned agent.
</ResponseField>

<ResponseField name="lenderUserId" type="integer">
  The user ID of the assigned lender, if any.
</ResponseField>

<ResponseField name="score" type="integer">
  The lead's engagement score.
</ResponseField>

<ResponseField name="tags" type="array">
  List of tag objects. Each entry contains `tagId` and `tagName`.
</ResponseField>

<ResponseField name="teamId" type="integer">
  The ID of the team that owns this lead.
</ResponseField>

<ResponseField name="createTime" type="string">
  The timestamp when the lead was created (ISO 8601).
</ResponseField>

<ResponseField name="assignTime" type="string">
  The timestamp when the lead was last assigned (ISO 8601).
</ResponseField>

<ResponseField name="referredBy" type="string">
  Name of the person who referred this lead.
</ResponseField>

<ResponseField name="hiddenFlag" type="boolean">
  Whether the lead is hidden from the default view.
</ResponseField>

<ResponseField name="cannotText" type="boolean">
  `true` if text messages are opted out for this lead.
</ResponseField>

<ResponseField name="cannotCall" type="boolean">
  `true` if calls are opted out for this lead.
</ResponseField>

<ResponseField name="cannotEmail" type="boolean">
  `true` if emails are opted out for this lead.
</ResponseField>
