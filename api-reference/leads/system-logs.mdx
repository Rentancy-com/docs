---
title: "Lead System Logs — GET /v1.0/systemLogs"
description: "Retrieve the system-generated audit trail of events on a Lofty lead, including stage changes, assignments, and agent actions, sorted newest first."
---

Returns a paginated, system-generated timeline of events for a specific lead. System logs are created automatically by Lofty whenever a significant action occurs — such as a stage change, reassignment, or property update. Entries are sorted by event time descending (newest first).

The authenticated user must be the lead's owner or a shared agent on that lead; otherwise the API returns `403`.

## Query parameters

<ParamField query="leadId" type="integer" required>
  The ID of the lead whose system logs you want to retrieve (64-bit integer).
</ParamField>

<ParamField query="pageNumber" type="integer">
  Zero-based page index. Defaults to 0.
</ParamField>

<ParamField query="pageSize" type="integer">
  Number of entries per page. Accepted range: 1–1000. Defaults to 100.
</ParamField>

<ParamField query="startTime" type="integer">
  Inclusive lower bound for event time, in milliseconds since Unix epoch (UTC). Pass `-1` to omit this filter.
</ParamField>

<ParamField query="endTime" type="integer">
  Inclusive upper bound for event time, in milliseconds since Unix epoch (UTC). Pass `-1` to omit this filter.
</ParamField>

## Example request

```bash
curl -G https://api.lofty.com/v1.0/systemLogs \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  --data-urlencode "leadId=563172647619608" \
  --data-urlencode "pageNumber=0" \
  --data-urlencode "pageSize=50"
```

## Response fields

<ResponseField name="hasMore" type="integer">
  Whether additional pages exist. `1` means more entries are available; `0` means this is the last page.
</ResponseField>

<ResponseField name="timeLines" type="array">
  Array of system log entries, sorted by event time descending.

  <Expandable title="timeline entry fields">
    <ResponseField name="id" type="integer">
      Unique ID of the timeline record (64-bit integer).
    </ResponseField>

    <ResponseField name="leadId" type="integer">
      The ID of the lead this entry belongs to.
    </ResponseField>

    <ResponseField name="agentId" type="integer">
      The ID of the agent who triggered the event. `0` for system-generated events.
    </ResponseField>

    <ResponseField name="timelineType" type="integer">
      Numeric code identifying the event type (e.g., stage change, assignment).
    </ResponseField>

    <ResponseField name="timelineTime" type="integer">
      The timestamp of the event in milliseconds since Unix epoch (UTC).
    </ResponseField>

    <ResponseField name="createTime" type="integer">
      The timestamp when this log record was created, in milliseconds since Unix epoch (UTC).
    </ResponseField>

    <ResponseField name="fromId" type="integer">
      The ID of the entity the change originated from (e.g., previous assignee ID).
    </ResponseField>

    <ResponseField name="fromType" type="integer">
      The type of the FROM entity.
    </ResponseField>

    <ResponseField name="toId" type="integer">
      The ID of the entity the change targets (e.g., new assignee ID).
    </ResponseField>

    <ResponseField name="toType" type="integer">
      The type of the TO entity.
    </ResponseField>

    <ResponseField name="leadFullName" type="string">
      The full name of the lead at the time of the event.
    </ResponseField>

    <ResponseField name="fromFirstName" type="string">
      First name of the FROM entity, when applicable.
    </ResponseField>

    <ResponseField name="fromLastName" type="string">
      Last name of the FROM entity, when applicable.
    </ResponseField>
  </Expandable>
</ResponseField>
