---
title: "PUT /v1.0/leads/{leadId} — Update a Lead"
description: "Partially update a Lofty lead using PUT /v1.0/leads/{leadId}. Change contact info, stage, tags, assignment, qualification fields, and custom attributes."
---

Updates an existing lead. The caller must have manage permission on the lead.

Only include the fields you want to change — omitted fields are left unchanged. One important exception: `tags` **replaces all existing tags** on the lead. To add tags without removing existing ones, use `tagsAdd` instead.

## Path parameters

<ParamField path="leadId" type="integer" required>
  The ID of the lead to update (64-bit integer).
</ParamField>

## Request body

## Example request

```bash
curl -X PUT https://api.lofty.com/v1.0/leads/563172647619608 \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "stage": "Contacted",
    "tagsAdd": ["Follow Up"],
    "buyingTimeFrame": "1-3",
    "preQual": "Yes"
  }'
```

## Response

On success, the API returns an empty string body with HTTP `200 OK`.

<Note>
  Include only the fields you want to change. Omitted fields retain their current values. Use `tagsAdd` instead of `tags` when you want to append tags without clearing the existing ones.
</Note>
