---
title: "GET /v1.0/getPublishedListings — Published Listings Feed"
description: "Retrieve your Lofty team's published listings as an XML feed for external syndication partners. Requires a feed type parameter; returns application/xml."
---

The published listings endpoint returns your team's listings as an XML feed, intended for syndication to external partners and portals. This is distinct from the [listings search endpoint](/api-reference/listings/search-listings), which queries MLS data — this endpoint returns listings your team has explicitly published through Lofty.

## Endpoint

```
GET https://api.lofty.com/v1.0/getPublishedListings
```

<Note>
  The response content type is `application/xml`, not JSON.
</Note>

## Query parameters

<ParamField query="type" type="string" required>
  Feed variant to emit. Controls the format and fields included in the XML output. Contact Lofty support for available feed type values for your integration.
</ParamField>

## Example request

```bash
curl "https://api.lofty.com/v1.0/getPublishedListings?type=standard" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

## Example response

```xml
<?xml version="1.0" encoding="UTF-8"?>
<listings>
  <listing>
    <id>563172647619608</id>
    <address>456 Oak Ave, Denver, CO 80202</address>
    <price>625000</price>
    <bedrooms>4</bedrooms>
    <bathrooms>3</bathrooms>
    <sqft>2400</sqft>
    <status>ACTIVE</status>
    <mlsNumber>9876543</mlsNumber>
    <publishedDate>2024-03-15</publishedDate>
  </listing>
</listings>
```
