---
title: "POST /v2.0/tasks — Create a Task or Appointment"
description: "Create a task or appointment on a Lofty lead. The type field determines whether a regular task or a scheduled appointment is created."
---

Creates a new task or appointment on the target lead. The `type` field controls which kind of entry is created: use `Appointment` for time-blocked calendar events with a location, or one of the task types (`Call`, `Email`, `Text`, `Other`) for action items.

<Note>
  Tasks and appointments share the same `taskId` namespace. An ID returned by this endpoint may refer to either type and is valid for `GET`, `PUT`, and `DELETE /v2.0/tasks/{taskId}`.
</Note>

<Note>
  The legacy `POST /v1.0/tasks` endpoint uses different field names (`content`, `deadline`, `type`, `assignedRole`). Prefer V2 for all new integrations.
</Note>

## Request body

<ParamField body="leadId" type="integer" required>
  ID of the lead this task belongs to. The caller must have manage permission on the lead.
</ParamField>

<ParamField body="type" type="string" required>
  The kind of entry to create. Accepted values: `Call`, `Email`, `Text`, `Other`, `Appointment`. Determines whether a task or appointment is created.
</ParamField>

<ParamField body="content" type="string">
  Description or title of the task. Required for meaningful entries — an empty `content` is accepted by the API but not recommended.
</ParamField>

<ParamField body="endAt" type="string" required>
  When this task or appointment ends (or expected completion time). ISO 8601 format with timezone, e.g., `2026-05-10T11:00:00GMT`.
</ParamField>

<ParamField body="startAt" type="string">
  When this task or appointment starts. ISO 8601 format with timezone, e.g., `2026-05-10T10:00:00GMT`. If omitted, `endAt` is used as the due time.
</ParamField>

<ParamField body="assignedRole" type="string">
  Role to assign the task to. Accepted values: `Agent`, `Assistant`.
</ParamField>

<ParamField body="timeZoneCode" type="string">
  IANA timezone code for interpreting `startAt` and `endAt`, e.g., `America/Los_Angeles`.
</ParamField>

<ParamField body="address" type="string">
  Location for `Appointment` type entries.
</ParamField>

## Example request

```bash
curl -X POST https://api.lofty.com/v2.0/tasks \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "leadId": 563172647619608,
    "type": "Call",
    "content": "Follow up on pre-approval letter",
    "startAt": "2026-05-10T10:00:00GMT",
    "endAt": "2026-05-10T10:30:00GMT",
    "assignedRole": "Agent",
    "timeZoneCode": "America/Los_Angeles"
  }'
```

### Appointment example

```bash
curl -X POST https://api.lofty.com/v2.0/tasks \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "leadId": 563172647619608,
    "type": "Appointment",
    "content": "Property showing — 123 Maple St",
    "startAt": "2026-05-12T14:00:00GMT",
    "endAt": "2026-05-12T15:00:00GMT",
    "address": "123 Maple St, Austin, TX 78701",
    "assignedRole": "Agent",
    "timeZoneCode": "America/Chicago"
  }'
```

## Response

```json
{
  "taskId": 88001
}
```

<Tip>
  Store the returned `taskId` to retrieve, update, or delete this entry later via `GET /v2.0/tasks/{taskId}`.
</Tip>
