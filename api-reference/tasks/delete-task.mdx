---
title: "DELETE /v2.0/tasks/{taskId} — Delete a Task or Appointment"
description: "Permanently delete a Lofty task or appointment by ID. Cannot be undone — use POST /v2.0/tasks/{taskId}/finish as a reversible soft-complete alternative."
---

Permanently deletes a task or appointment by ID. The caller must have manage permission on the lead that owns the entry. The response body is empty on success.

<Warning>
  Deletion is irreversible. If you want to mark a task as complete without removing it, use `POST /v2.0/tasks/{taskId}/finish` instead. To undo a completion, use `POST /v2.0/tasks/{taskId}/unfinish`.
</Warning>

## Path parameters

<ParamField path="taskId" type="integer" required>
  ID of the task or appointment to delete.
</ParamField>

## Example request

```bash
curl -X DELETE https://api.lofty.com/v2.0/tasks/88001 \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json"
```

## Response

Returns an empty body with HTTP `200` on success.

```json
{}
```

## Soft-complete alternative

If the goal is to mark a task done rather than remove it from the record, use the finish and unfinish endpoints:

| Endpoint | Description |
|---|---|
| `POST /v2.0/tasks/{taskId}/finish` | Mark as complete (reversible) |
| `POST /v2.0/tasks/{taskId}/unfinish` | Revert to incomplete |

```bash
# Mark complete instead of deleting
curl -X POST https://api.lofty.com/v2.0/tasks/88001/finish \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json"
```

<Note>
  Smart-plan tasks cannot be deleted through this endpoint if they are managed by Lofty's AI plan system. Attempting to do so returns `TASK_IS_SMARTPLAN`.
</Note>
