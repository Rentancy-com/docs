---
title: "Create a Transaction — Lofty API"
description: "Create a new real estate transaction associated with a lead in Lofty. Supports buy and sell transaction types with commission details."
---

Use this endpoint to create a transaction linked to a lead in Lofty. A transaction represents a real estate deal — a purchase or a sale — and tracks details like price, close date, and commission.

## Endpoint

```
POST https://api.lofty.com/v1.0/leads/{leadId}/transaction
```

## Path parameters

<ParamField path="leadId" type="integer" required>
  ID of the lead to associate this transaction with. Must be manageable by the caller.
</ParamField>

## Request body

<ParamField body="transactionName" type="string" required>
  Property address or deal name. Must not be blank or contain `<` or `>` characters.
</ParamField>

<ParamField body="transactionType" type="string">
  Type of transaction: `BUY` or `SELL`.
</ParamField>

<ParamField body="status" type="string">
  Transaction status (e.g., `IN_PROGRESS`, `CLOSED`, `CANCELLED`).
</ParamField>

<ParamField body="homePrice" type="number">
  Property price in USD.
</ParamField>

<ParamField body="closeDate" type="string">
  Expected or actual close date in `YYYY-MM-DD` format.
</ParamField>

<ParamField body="commission" type="object">
  Commission details object. Fields: `desc` (string, up to 512 chars), `payType` (required if commission provided), `commissionRate` (decimal), `commissionAmount` (USD).
</ParamField>

## Example request

```bash
curl -X POST "https://api.lofty.com/v1.0/leads/563172647619608/transaction" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "transactionName": "456 Oak Ave Purchase",
    "transactionType": "BUY",
    "status": "IN_PROGRESS",
    "homePrice": 625000,
    "closeDate": "2024-07-15",
    "commission": {
      "payType": "PERCENTAGE",
      "commissionRate": 2.5
    }
  }'
```

## Example response

{

  "homePrice": 625000,
  "closeDate": "2024-07-15",
  "createdAt": "2024-04-01T14:30:00Z"
