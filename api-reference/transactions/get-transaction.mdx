---
title: "GET /v1.0/leads/{leadId}/transaction/{transactionId}"
description: "Retrieve a single transaction by ID from a lead in Lofty. Returns full transaction details including commission, property address, and custom fields."
---

This endpoint fetches a single transaction associated with a specific lead. Both the lead and the transaction must belong to your team and the transaction must be linked to the specified lead.

## Endpoint

```
GET https://api.lofty.com/v1.0/leads/{leadId}/transaction/{transactionId}
```

## Path parameters

<ParamField path="leadId" type="integer" required>
  ID of the lead that owns the transaction. Must be manageable by the caller.
</ParamField>

<ParamField path="transactionId" type="integer" required>
  ID of the transaction to retrieve. Must exist, not be deleted, and belong to the specified `leadId`. Cross-lead transaction IDs are treated as not found for security.
</ParamField>

## Example request

```bash
curl "https://api.lofty.com/v1.0/leads/563172647619608/transaction/789012345678902" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

<Tip>
  To retrieve all custom field definitions available for transactions, call `GET /v1.0/transaction/customfields`.
</Tip>

You can also partially update a transaction using `PUT /v1.0/leads/{leadId}/transaction/{transactionId}`. Fields absent from the request body are left unchanged.
