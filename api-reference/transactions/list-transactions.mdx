---
title: "List Transactions — GET /v2.0/transactions"
description: "Search and paginate across all transactions in your team using keyword search, lead filter, and pagination. Also covers listing a single lead's transactions."
---

The Lofty API provides two ways to list transactions: a global search across all team transactions, and a lead-scoped listing for transactions on a specific lead.

## Global search

```
GET https://api.lofty.com/v2.0/transactions
```

<ParamField query="queryKey" type="string">
  Search keyword. Performs a fuzzy contains-match (first 15 characters used) against transaction name, property address, or associated lead name.
</ParamField>

<ParamField query="leadId" type="integer">
  Restrict results to transactions belonging to this lead.
</ParamField>

<ParamField query="pageNum" type="integer">
  Page number (0-based). Defaults to `0`.
</ParamField>

<ParamField query="pageSize" type="integer">
  Results per page. Must be between 1 and 100.
</ParamField>

```bash
curl "https://api.lofty.com/v2.0/transactions?queryKey=Main+St&pageSize=20" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

## Lead-scoped list

```
GET https://api.lofty.com/v1.0/leads/{leadId}/transactions
```

<ParamField path="leadId" type="integer" required>
  ID of the lead whose transactions to list. Must be manageable by the caller.
</ParamField>

```bash
curl "https://api.lofty.com/v1.0/leads/563172647619608/transactions" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```
