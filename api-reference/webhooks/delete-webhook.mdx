---
title: "DELETE /v1.0/webhook/{subscribeId} — Remove a Webhook"
description: "Remove a Lofty webhook subscription using DELETE /v1.0/webhook/{subscribeId}. Stops event delivery for that event type to the registered endpoint immediately."
---

Delete a webhook subscription to stop Lofty from sending event notifications to the associated endpoint. The subscription must belong to your team.

## Endpoint

```
DELETE https://api.lofty.com/v1.0/webhook/{subscribeId}
```

## Path parameters

<ParamField path="subscribeId" type="string" required>
  ID of the webhook subscription to delete. Retrieve subscription IDs from [GET /v1.0/webhooks](/api-reference/webhooks/list-webhooks).
</ParamField>

## Example request

```bash
curl -X DELETE "https://api.lofty.com/v1.0/webhook/sub_111222333" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json"
```

Returns an empty `200 OK` response on success.

<Warning>
  Deleting a subscription is immediate. Any in-flight events already queued for delivery may still arrive at your endpoint briefly after deletion.
</Warning>
