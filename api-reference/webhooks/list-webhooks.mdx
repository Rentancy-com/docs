---
title: "GET /v1.0/webhooks — List Webhook Subscriptions"
description: "Retrieve all active webhook subscriptions for your Lofty team using GET /v1.0/webhooks. Returns event type, endpoint URL, subscription ID, and creation date."
---

This endpoint returns all webhook subscriptions your team has registered. Each subscription maps an event type to a URL where Lofty will send HTTP POST notifications when that event fires.

## Endpoint

```
GET https://api.lofty.com/v1.0/webhooks
```

## Example request

```bash
curl "https://api.lofty.com/v1.0/webhooks" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

## Example response

```json
{
  "subscriptions": [
    {
      "subscribeId": "sub_111222333",
      "eventType": 1,
      "eventName": "NEW_LEAD",
      "url": "https://yourapp.com/webhooks/lofty",
      "createdAt": "2024-01-15T10:00:00Z"
    },
    {
      "subscribeId": "sub_444555666",
      "eventType": 5,
      "eventName": "LEAD_STAGE_CHANGE",
      "url": "https://yourapp.com/webhooks/lofty",
      "createdAt": "2024-02-01T08:30:00Z"
    }
  ]
}
```

## Event types

| Event type ID | Name | Description |
|---|---|---|
| 1 | NEW_LEAD | A new lead is created |
| 2 | LEAD_ASSIGNED | A lead is assigned to an agent |
| 3 | NEW_INQUIRY | A lead submits a property inquiry |
| 4 | NEW_APPOINTMENT | An appointment is scheduled |
| 5 | LEAD_STAGE_CHANGE | A lead's stage changes |
| 6 | NEW_NOTE | A note is added to a lead |
| 7 | NEW_CALL | A call is logged for a lead |
| 8 | NEW_TEXT | A text message is sent or received |
| 9 | NEW_EMAIL | An email is sent or received |
| 10 | TRANSACTION_UPDATE | A transaction is created or updated |
| 11 | LEAD_DELETED | A lead is deleted |
| 12 | TASK_UPDATE | A task is created or updated |
