## Overview

```bash
Usage: lofty-cli intelligent-features [options] [command]

Manage intelligent-features

Options:
  -h, --help                    display help for command

Commands:
  prepare-insight [options]     Generate Prepare Insight
  lead-analysis [options]       Query LeadAnalysis task list
  post-lead-analysis [options]  Create LeadAnalysis task
  generate [options]            Trigger Call Summary generation
  call-script [options]         Generate Call Script
  call-summary [options]        Get Call Summary
  help [command]                display help for command
```
